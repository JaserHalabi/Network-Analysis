# Network Security and Vulnerability Analysis

A collection of network security labs, packet captures, scripts, and analysis write-ups from my coursework and self-study. The focus is on understanding real network traffic and identifying vulnerabilities using tools like Wireshark, Nmap, and Python.

---

## Repository Structure

```
labs/           Lab reports and written analysis
captures/       Wireshark .pcap and .pcapng capture files
screenshots/    Annotated screenshots and diagrams
scripts/        Python and Bash analysis scripts
resources/      Reference material and cheat sheets
```

## Tools Used

- Wireshark - packet capture and protocol inspection
- tcpdump - command-line packet capture
- Nmap - network scanning and enumeration
- Python (Scapy) - packet crafting and scripting
- Nessus / OpenVAS - vulnerability scanning (where applicable)

---

## How to Use

Open any .pcap or .pcapng file directly in Wireshark.

For scripts, install dependencies first:

```bash
pip install -r scripts/requirements.txt
```
